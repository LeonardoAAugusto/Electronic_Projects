# Analisador de Espectro RF Portatil (3,3 V)

Projeto de placa de circuito impresso (PCB) desenvolvido no EasyEDA para um analisador de espectro RF portatil alimentado em 3,3 V[cite: 3, 4].

## Principais Blocos e Componentes

- Microcontrolador: ESP32-WROOM-32[cite: 4].
- Front-end de RF: RTL2832U com conector SMA e cristal de 28,8 MHz[cite: 3, 4].
- Alimentacao e regulacao: entrada USB-C e regulador linear AMS1117-3.3 com capacitores de desacoplamento[cite: 3, 4].
- Interfaces e exibicao: comunicacao I2C com o bloco de RF, display OLED via SPI e botoes de controle[cite: 4].
