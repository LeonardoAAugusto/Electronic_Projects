# Circuito de Condicionamento Analogico - Prova 2

Esquematico desenvolvido no EasyEDA envolvendo regulacao linear de tensao e condicionamento de sinais analogicos[cite: 11].

## Principais Blocos e Componentes

- Alimentacao e regulacao: regulador linear AMS1117-5.0 com capacitores de desacoplamento a partir de barramento de 12 V[cite: 11].
- Sensoriamento e amplificacao: sensor de temperatura LM35CZ/LFT1 e divisor resistivo com LDR GL5516 conectados a estagios com amplificador operacional LM358[cite: 11].
- Conexoes: conector de saida/interface de 5 pinos e pontos de fixacao mecanica[cite: 11].
